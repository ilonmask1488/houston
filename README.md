# Houston — английский: эфир, позывной, техдок

Приложение для ежедневной тренировки английского: быстрая речь на слух, говорение с таймером, собеседования, деловая переписка и чтение технических текстов.
Работает в браузере телефона, ставится на главный экран как обычное приложение и работает без интернета.
Без аккаунтов, рекламы и аналитики: прогресс хранится только на твоём устройстве.

«Младший брат» приложения для китайского «小火 · Сяо Хо»: тот же движок, свои методика и содержание. Прогресс и бэкапы двух приложений независимы.

Техническое задание — [docs/SPEC.md](docs/SPEC.md), план и принятые решения — [docs/PLAN.md](docs/PLAN.md).

Готово:
- **Фаза 0 — каркас и вводный тест.** Пять разделов («Сеанс», «Треки», «Мой рассказ», «Словарь», «Ещё»), дизайн «пульт связи», маскот Ping, проверка звука и микрофона, вводный тест на 15–20 минут (словарь по частотным полосам с псевдословами, аудирование на трёх скоростях и двух акцентах, «близнецы», технический текст, три ответа вслух с записью и распознаванием), профиль по пяти трекам, ориентировочный уровень CEFR и стартовые модули. Бэкап, настройки, офлайн.
- **Фаза 1 — Эфир и Позывной.** Эфир: пять явлений связной речи (слабые формы, слияние, выпадение, уподобление, сокращения) с объяснениями и 60 фразами, акценты (10 фраз голосами US, UK, Индии и Австралии), 6 длинных отрывков (планёрка, созвон с поставщиком, собеседование, разбор испытаний, перенос ревью, экскурсия по стенду); упражнения «что прозвучало», диктант по кусочкам с подсветкой потерянных слов, лестница скоростей 0.75 → 1.0 → 1.25. Позывной: банк из 68 чанков по семи функциям, быстрый ответ (вопрос → таймер на начало → запись, время до начала ответа, длительность речи, долгие паузы, распознанный текст), перевод на лету, подстановка. Интервальное повторение FSRS (чанк → значение, значение → скажи вслух, на слух → понять; пропущенные фразы возвращаются карточками). Ежедневный «Сеанс связи» из сегментов не длиннее 3 минут. Игры «Помехи» (фраза сквозь радиошум, скорость растёт с серией) и «Быстрый ответ». Уровень сигнала, дни в эфире с резервным каналом, 13 достижений, статистика, словарь чанков с поиском, свободная тренировка любого модуля из «Треков».
- **Фаза 2 — «Мой рассказ» и собеседования.** Десять типовых вопросов собеседования (о себе, проект, почему мы, сильные и слабые стороны, трудная задача, команда и неудача по STAR, пять лет, вопросы работодателю) с советами, образцами ответов инженера и подходящими чанками; редактор своего ответа с автосохранением и счётчиком времени звучания. Тренировка своего ответа: озвучка синтезом браузера, шэдоуинг по фразам с паузой «твоя очередь», ответ по опорным словам, ответ без подсказок с таймером. Упражнение 4/3/2. Пробное собеседование (5 или 7 вопросов подряд, запись, транскрипт, время до начала ответа, паузы). Связка с Claude: «Отредактировать с Claude», «Разобрать с Claude», «Практика разговора» — промпт копируется в буфер, шаблоны в `src/i18n/claude-prompts.ts`. Сюжет «Международный проект», эпизоды 1–3 (собеседование, первый день, созвон с разными акцентами) с персонажами и культурными вставками. Свой ответ попадает в ежедневный сеанс.
- **Фаза 3 — Техдок.** Шесть модулей со стратегиями чтения (структура статьи, аннотация и выводы, грамматика технического текста, документация и даташиты, стандарты и требования, скорость) и 19 технических текстов трёх уровней по темам: космос, двигатели, композиты, прочность и испытания, CAD, датчики. Упражнения: чтение с таймером и скоростью в словах в минуту, найти ответ на время (30–60 с), лучшее краткое содержание абзаца, разбор сложного предложения, **пересказ абзаца вслух** с образцом. Тап по любому слову: перевод из встроенного словаря (≈3700 частых и академических слов NGSL/NAWL и ≈350 технических терминов с транскрипцией и звуком), «В карточки», свой перевод, «Спросить Claude»; «Объясни абзац с Claude». Библиотека текстов, «Мой текст» (вставить абзац из настоящей статьи — тап по словам, озвучка по предложениям, хранится только на устройстве), вкладка «Слова» в словаре, игра «Скорочтение», чтение в статистике, 4 новых достижения. Техдок стоит в ротации ежедневного сеанса.
- **Фаза 4 — Телеграмма и Чистый сигнал.** Телеграмма: шесть модулей (структура письма, регистр, отклик и благодарность, запрос и напоминание, уточнить/отказать/перенести, отчёт о статусе) — выбрать фразу нужного регистра, найти «слишком по-русски» написанную фразу и заменить, собрать письмо из блоков, написать самому → сравнить с образцом и чек-листом → «Проверить с Claude»; банк из 37 готовых фраз в словаре (вкладка «Письма»). Чистый сигнал: восемь модулей (th, w/v, h, долгие и краткие гласные, звонкие на конце, ŋ, ударение в технических словах, вежливая интонация) — 42 минимальные пары на слух и вслух (распознавание проверяет, какое слово услышано), фразы для постановки звука, ударение (24 слова: techNOLogy, maTErial, paRAMeter…), интонация с графиком тона «образец / ты». 26 инженерных «ложных друзей» (конструкция ≠ construction, деталь ≠ detail, прочность ≠ durability…) — в сеансе, в карточках повторения и в словаре. Игры «Близнецы» и «Ложные друзья». Эпизоды сюжета 4–6 (испытания и отчёт, письмо поставщику, презентация результатов). Боссы треков: длинный созвон (Эфир), пробное собеседование (Позывной), статья на время (Техдок), письмо «сложному» заказчику (Телеграмма). Ротация сеанса по дням: Техдок / Телеграмма / Чистый сигнал, слабому треку — вдвое чаще.

## 1. Что нужно установить (один раз)

Три программы: **Node.js LTS** (собирает и запускает приложение), **Git** (история и публикация на GitHub) и **Python 3** (генерация звука).

### Windows (PowerShell)

```powershell
winget install OpenJS.NodeJS.LTS
winget install Git.Git
winget install Python.Python.3.12
```

Закрой PowerShell и открой заново. Проверка: `node -v`, `git --version`, `python --version`.

### macOS

```bash
brew install node git python
```

### Linux (Ubuntu/Debian)

```bash
sudo apt install git python3 python3-venv
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt install nodejs
```

## 2. Первый запуск на компьютере

```powershell
cd путь\к\папке\houston
npm install
npm run dev
```

Открой адрес, который покажет команда (обычно http://localhost:5173). Остановить — `Ctrl+C`.

## 3. Посмотреть на телефоне в той же Wi-Fi сети

```powershell
npm run dev -- --host
```

Команда покажет `Network: http://192.168.x.x:5173` — открой этот адрес на телефоне. Если Windows спросит про брандмауэр, разреши доступ **для частных сетей**.

> ⚠️ По обычному `http://` браузеры не дают микрофон, установку на главный экран и офлайн. По Wi-Fi удобно смотреть вёрстку, а «настоящее» приложение живёт на GitHub Pages (раздел 6).

## 4. Проверки

```powershell
npm test                   # юнит-тесты: база, миграции, бэкап, подсчёт теста, детектор речи, распознавание
npm run check:content      # контроль контента: полосы частотности, звук, доля непроверенного
npx playwright install chromium webkit   # один раз: браузеры для e2e (~250 МБ)
npm run e2e                # сквозные тесты на вьюпортах Android и iPhone
npm run build              # сборка в папку dist
```

Скриншоты экранов: `$env:SCREENS='phase0'; npx playwright test screens` (Windows) или `SCREENS=phase0 npx playwright test screens` — картинки появятся в `docs/screens/phase0/`.

## 5. Звук

Готовые файлы уже лежат в `public/audio` — пересоздавать их нужно, только когда меняется учебный контент.

Образцы озвучены заранее синтезом речи Microsoft Edge (`edge-tts`) разными акцентами: американский (Ava, Andrew), британский (Sonia, Ryan), индийский (Neerja, Prabhat), австралийский (Natasha, William). Это неофициальный доступ к сервису Microsoft для личного использования; интернет нужен **только при сборке звука**, приложению — нет. Скорости 0.75 и 1.25 приложение делает само из записи на 1.0, высота голоса при этом не меняется.

Один раз подготовить окружение (Windows):

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r scripts\requirements.txt
```

Пересоздать звук:

```powershell
.venv\Scripts\python.exe scripts\generate_audio.py
npm run check:content
```

На macOS/Linux то же через `python3 -m venv .venv` и `.venv/bin/python`. Если `edge-tts` не отвечает (сервис Microsoft бывает недоступен из России), скрипт напишет об этом — попробуй позже, из другой сети или через VPN; уже скачанное лежит в кэше `scripts/.cache`.

**Проверь на слух:** фразы со связной речью (gonna, should've, did you…) скрипт выписывает в [docs/audio-review.md](docs/audio-review.md). Синтез может прочитать их слишком «по-книжному» — отметь такие в файле.

### Как править учебный контент

Фразы Эфира, отрывки, чанки, вопросы и упражнения Позывного записаны компактно в `scripts/author_phase1.py`. После правки:

```powershell
.venv\Scripts\python.exe scripts\author_phase1.py
.venv\Scripts\python.exe scripts\generate_audio.py
npm run check:content
```

Вопросы «Моего рассказа» с образцами ответов и эпизоды сюжета — в `scripts/author_phase2.py` (запуск так же, затем `generate_audio.py`).

Письма, банк фраз, минимальные пары, фразы и ударение, ложные друзья, эпизоды 4–6 и боссы — в `scripts/author_phase4.py`. Тексты Техдока, стратегии чтения и словарь — в `scripts/author_phase3.py`; переводы слов лежат простыми списками `data/dict/*.txt` (`слово|перевод`, для терминов `термин|транскрипция|перевод|тема`) — поправь строку и запусти `author_phase3.py`.

Всё сгенерированное помечено `reviewed: false`; `check:content` проверяет, что у каждой фразы первый вариант совпадает с текстом, «стык» есть в тексте, у отрывков есть персонажи, чанки не повторяются, ключ «найди ответ» стоит ровно в одном предложении текста, у словарных терминов есть транскрипция, и у всего есть звук.

## 6. Публикация на GitHub Pages (постоянный адрес с https)

Один раз:

1. Зайди на [github.com](https://github.com) и создай **новый пустой** репозиторий `houston` (кнопка «New», галочки «Add README» и прочие не ставь). Репозиторий «Сяо Хо» не трогаем.
2. В папке проекта выполни (подставь свой логин):
   ```powershell
   git remote add origin https://github.com/ЛОГИН/houston.git
   git push -u origin main
   ```
   Git попросит войти в GitHub — откроется окно браузера.
3. На GitHub: репозиторий → **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Вкладка **Actions** покажет запуск «Проверка и публикация». Когда он станет зелёным (5–10 минут), приложение будет по адресу `https://ЛОГИН.github.io/houston/`.

Дальше каждое `git push` в ветку `main` прогоняет тесты и, если они зелёные, обновляет сайт.

> ⚠️ **Доступность из России.** GitHub Pages обычно открывается, но у отдельных провайдеров бывают перебои. Проверь адрес с телефона через мобильный интернет и через домашний Wi-Fi. Установленному приложению сеть нужна только для обновлений.

## 7. Установка на телефон

- **Android (Chrome):** на главном экране приложения появится «Установить», либо меню ⋮ → «Установить приложение».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“». **Обязательно установи:** Safari стирает данные сайтов, которые не открывались 7 дней и не установлены.

## 8. Что проверить на телефоне (фаза 0)

1. Открой приложение с иконки-спутника. На главном — Ping и «Сначала — настройка связи».
2. «Ещё → Проверка звука и микрофона»: «Послушать» — два голоса, американский и британский. «Записать» → скажи «Houston, we have a problem» → столбики прыгают, после «Стоп» — «Послушать себя» и, если браузер умеет, распознанный текст.
3. **Запись и распознавание на iPhone проверь обязательно**: в автотестах их можно проверить только в Chrome. Если что-то не работает — напиши, что именно видно на экране.
4. «Начать вводный тест»: словарь (некоторые слова выдуманные; на «Знаю» иногда спрошу перевод), фразы на слух (скорость растёт, пока ловишь), два похожих слова, технический текст, три вопроса вслух.
5. Выйди из теста крестиком посередине и вернись: «Продолжить вводный тест» продолжит с того же места.
6. После теста — профиль: уровень, пять треков с баллами и стартовым модулем, где были помехи. На главном — циклограмма сеанса на 30 минут (сами сеансы появятся в фазе 1).
7. «Треки»: стартовый модуль каждого трека отмечен янтарной полосой.
8. «Ещё → Настройки»: длительность 20/30/45, вариант US/UK, голос, акценты, время на ответ, распознавание, тема, бэкап.

## 8а. Что проверить на телефоне (фаза 1)

1. После вводного теста на главном — «Начать сеанс». Откроется список сегментов на сегодня: разминка, Эфир, Позывной, ротация; у каждого — время и модуль.
2. «Разминка» — игра «Помехи»: фраза звучит сквозь тихий радиошум, выбери, что сказали. Чем длиннее серия, тем быстрее речь. Шум выключается вместе со звуковыми эффектами в настройках.
3. «Эфир»: сначала объяснение явления с примерами (подсвечен «стык»), потом «что прозвучало», диктант (напиши, что слышишь, — увидишь, где потерялся), лестница скоростей. После ответа можно переслушать на 0.75.
4. «Позывной»: новый чанк → «Записать себя» → повтори вслух → «Образец → я → образец». Быстрый ответ: вопрос звучит сам, отсчёт до начала ответа, говори 20–40 секунд. **Проверь на iPhone и на Android, работают ли запись и распознавание одновременно** — если телефон не даёт микрофон двоим, приложение само перейдёт на одно распознавание и напишет об этом в «Проверке звука и микрофона».
5. Перевод на лету: русская фраза, у тебя 7 секунд, чтобы начать; потом образец и самооценка.
6. Выйди из сегмента крестиком посередине: в списке сеанса появится «продолжить с N-го шага».
7. На следующий день появится «Повторение» — карточки чанков и фраз, которые не поймал. Оценки «Снова / Трудно / Хорошо / Легко» подписаны, через сколько карточка вернётся.
8. «Треки»: у модулей кнопка «Тренировать» — свободный круг минут на пять; текущий модуль отмечен ◂, пройденный — ✓.
9. «Словарь»: чанки по функциям с поиском по-русски и по-английски; «В повторение» — добавить чанк в карточки. «Фразы Эфира» — всё, что уже встречалось.
10. «Ещё → Мини-игры» и «Ещё → Статистика»: минуты по дням (янтарная часть — речь вслух), скорость, на которой понимаешь, время до начала ответа.
11. Послушай фразы из [docs/audio-review.md](docs/audio-review.md): если синтез где-то говорит слишком «по-книжному», отметь это в файле.

## 8б. Что проверить на телефоне (фаза 2)

1. «Мой рассказ» → «Tell me about yourself.» → прочитай совет и пример, напиши свой ответ (можно вставлять чанки кнопкой «вставить»). Внизу — сколько слов и сколько секунд он звучит.
2. «Отредактировать с Claude» → «Промпт скопирован» → вставь в чат с Claude: он поправит ответ, сохранив твой уровень.
3. «Тренировать ответ»: «Озвучить» (**проверь, что на телефоне есть английский голос** — это синтез браузера), шэдоуинг с паузой «твоя очередь», ответ по опорным словам, ответ без подсказок с таймером.
4. «4/3/2 на этом ответе» (от 40 слов): расскажи ту же историю за 4, 3 и 2 минуты — в таблице видно, как растёт беглость.
5. «Пробное собеседование»: вопросы идут подряд, отвечай вслух. В итогах — транскрипт (если браузер распознаёт речь), «Послушать» свои ответы, «Разобрать с Claude».
6. «Треки» → внизу «Сюжет»: эпизоды 1–3. Реплики звучат голосами персонажей (американский, британский, индийский, австралийский), твой ответ — выбрать и сказать вслух; в конце — культурная вставка и «Практика разговора с Claude».
7. После того как написал хотя бы один ответ, в «Сеансе связи» в блоке Позывной появится «„Мой рассказ“ вслух».
8. «Сбросить прогресс» в настройках не трогает твои ответы в «Моём рассказе» — они удаляются только кнопкой «Удалить ответ».

## 8в. Что проверить на телефоне (фаза 3)

1. «Треки» → Техдок → «Библиотека текстов · Мой текст» → любой текст. Нажми на незнакомое слово: снизу — перевод, транскрипция, звук, «В карточки». Для слова, которого нет в словаре, — поле «Свой перевод» и «Спросить Claude».
2. Под абзацем «Слушать» — абзац читается по предложениям с подсветкой (голос телефона). «Объясни абзац с Claude» копирует промпт.
3. «Задания по тексту»: прочитал (внизу скорость в словах в минуту) → найди ответ, пока идёт таймер, — нажми на предложение → краткое содержание → разбор длинного предложения → **перескажи абзац вслух** и сравни с образцом.
4. В «Сеансе связи» блок «Ротация» теперь — Техдок: текст на два сегмента по ~3 минуты.
5. «Словарь» → «Слова»: добавленные слова, технические термины по темам (нажми на тему), поиск по всему словарю по-русски и по-английски (формы тоже: tested → test).
6. На следующий день слова придут в «Повторение»: слово → значение, у терминов — ещё «на слух».
7. «Ещё → Мини-игры → Скорочтение»: шесть вопросов, с серией таймер короче.
8. «Библиотека → Мой текст»: вставь абзац из настоящей статьи — тапай слова, слушай. Текст никуда не уходит.
9. «Ещё → Статистика» → «Чтение»: скорость чтения, найденные ответы, слова по частотности.

## 8г. Что проверить на телефоне (фаза 4)

1. «Треки» → Телеграмма → «Структура письма» → «Тренировать»: выбери фразу нужного регистра, замени «слишком по-русски» написанную фразу, собери письмо из блоков (нажимай по порядку; нажатие на блок в письме возвращает его).
2. В упражнении «Напиши сам»: напиши письмо → «Сравнить с образцом» → отметь пункты чек-листа → «Проверить с Claude» копирует промпт с твоим письмом.
3. «Словарь» → «Письма»: готовые фразы по ситуациям, у каждой — регистр. Поиск работает по-русски и по-английски.
4. Чистый сигнал → «th»: объяснение с парами (think — sink), потом «какое слово прозвучало», потом скажи слово сам — **проверь на iPhone и Android, распознаёт ли телефон отдельное слово** (если нет — приложение предложит сравнить самому).
5. «Ударение»: нажми на ударный слог — после ответа слово прозвучит.
6. «Вежливая интонация»: запиши фразу → «График тона» — сплошная линия образец, пунктир ты. **Проверь на iPhone**, что график рисуется (в автотестах запись есть только в Chrome).
7. «Ещё → Мини-игры»: «Близнецы» (с серии 4 слова звучат разными голосами) и «Ложные друзья». Ошибки из «Ложных друзей» придут в «Повторение».
8. «Треки»: у Эфира, Позывного, Техдока и Телеграммы внизу — «Босс трека». Пройденный босс отмечается, за каждого — достижение.
9. «Треки» → «Сюжет»: эпизоды 4–6.
10. «Сеанс связи»: блок «Ротация» по дням меняется — Техдок, Телеграмма, Чистый сигнал; слабый по вводному тесту трек выпадает чаще.

## 9. Бэкап и перенос прогресса

«Ещё → Настройки → Сохранить бэкап» сохраняет весь прогресс одним файлом `houston-backup-ДАТА.json`; «Загрузить бэкап» на другом устройстве переносит всё целиком. Раз в две недели приложение напомнит. Бэкап «Сяо Хо» сюда не загрузится — приложение так и скажет.

## 10. Обновление

- Код поменялся → `git push` → через несколько минут сайт обновлён; установленное приложение покажет «Готова новая версия · Обновить».
- Прогресс при обновлении не теряется: схема базы версионируется, тест `src/lib/db/migrations.test.ts` проверяет, что данные каждой прошлой версии переживают обновление.
