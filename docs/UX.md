# Houston: понятный интерфейс — ТЗ для Claude Code

Положи в `docs/UX.md`. Этот файл дополняет `docs/SPEC.md`, при противоречии прав этот файл.

## 0. Проблема

Приложение готово функционально (фазы 0–4), но пользователь в нём **теряется**. Про «Сяо Хо» он сказал, и это полностью относится к Houston:

- «Я не понимаю, что от меня требуется» на экранах упражнений и карточек.
- «Что значат "Снова", "Трудно", "Хорошо", "Легко"? Что за минуты под ними?»
- «Хочу видеть перевод того, что меня просят сказать».
- «Где основной путь обучения?»
- «Нужен интуитивно понятный интерфейс».

**Цель:** человек, открывший приложение впервые, без объяснений понимает, куда нажать, чтобы учиться, и на любом экране понимает, что от него требуется.

Тему «сеанса связи», маскота Ping и юмор **не убирать**. Метафора становится украшением, а не единственным способом понять интерфейс.

Если в соседнем проекте `../xiao-huo` уже есть `docs/UX.md` и реализованные по нему компоненты (карточки повторения, всплывающий перевод, коучмарки, кнопка «?»), **переиспользуй их** — оба приложения должны вести себя одинаково.

## 1. Главные правила (для всех экранов)

1. **Три вопроса.** На любом экране за 3 секунды понятно: **где я? что от меня требуется? что будет, когда я нажму?** Если нет — экран переделывается.
2. **Сначала понятное название, потом метафора.** «Аудирование» крупно, «Эфир» мелко рядом. Никогда не только метафора.
3. **Инструкция глаголом и по шагам:** «Послушай фразу и выбери, что прозвучало», при нескольких шагах — строка «1. Слушай → 2. Выбери → 3. Проверь».
4. **Один путь к одному действию.** Не два способа начать одно и то же на одном экране.
5. **Одно главное действие на экране** — крупная кнопка внизу.
6. **Перевод в одном тапе.** Тап по любому английскому слову → перевод, звук, «в карточки». Кнопка «Перевод» у любой фразы и предложения. В упражнениях на понимание перевод скрыт до ответа, но кнопка «Подсказка» есть всегда.
7. **Любой значок и число объясняются тапом** (1–2 предложения).
8. **Кнопка «?» на каждом экране упражнения** — «как работает это упражнение».
9. **Простой русский.** Без слов «чанк», «ротация», «сегмент», «трек», FSRS, CEFR без пояснения.
10. **Никогда не блокировать без выхода.** Если упражнение просит микрофон — всегда есть вариант «Сказал вслух без записи».

## 3. Навигация

### 3.1. Вкладки

| Сейчас | Станет | Что внутри |
|---|---|---|
| Сеанс | **Сегодня** | занятие на сегодня |
| Треки | **Курс** | пять направлений, где я в каждом, что дальше |
| Мой рассказ | **Собеседование** | «Мой рассказ» и пробное собеседование |
| Словарь | **Словарь** | слова, готовые фразы, ложные друзья |
| Ещё | **Тренировка** | мини-игры, библиотека текстов, «Мой текст», сюжет, слабые звуки |

**Профиль, статистика, достижения, настройки, проверка звука, «О приложении»** — через значок профиля в правом верхнем углу экрана «Сегодня» (и пункт в «Тренировке» внизу списка). Сейчас мини-игры и библиотека текстов спрятаны в «Ещё» между настройками — это главная причина, почему их не находят.

### 3.2. Экран «Сегодня»

Сверху вниз, **главная кнопка видна без прокрутки**:
1. Строка статуса: «🔥 3 дня подряд · Очки 420» (тап — объяснение).
2. **Карточка «Занятие на сегодня»:** что будет простыми словами и время — «Разминка-игра · Повторить 14 фраз · Быстрая речь на слух · Говорим вслух · Сегодня: чтение · ~30 мин». Кнопка **«Начать занятие»** / «Продолжить» / «Выполнено ✓ — можно потренироваться ещё».
3. Маскот с репликой — маленький.
4. **Профиль сжать до одной строки:** «Уровень ≈ B1 · сильнее всего чтение, слабее всего говорение» → тап открывает профиль. Большие полосы по трекам — в «Курсе» и профиле, не на главном.
5. Баннер «Установи на главный экран» — один раз, после закрытия не возвращается месяц.

### 3.3. Экран занятия (сейчас «Сеанс связи»)

Сейчас у каждого блока кнопка «Открыть», плюс внизу «Начать: Разминка» и «Пропустить блок» — **три способа сделать одно**. Переделать:
- Список блоков — **только превью** плана (без кнопок у каждого), текущий блок выделен.
- Одна кнопка «**Начать занятие**»: блоки идут подряд автоматически, между блоками — короткий экран «Готово: Разминка ✓ → Дальше: Быстрая речь на слух, 3 мин» с кнопками «Дальше» и мелкой «Пропустить этот блок».
- Отметки T+00 оставить как мелкий декор слева, не как главное.
- Названия блоков по смыслу: «Разминка (игра)», «Повторение фраз и слов», «Быстрая речь на слух», «Говорим вслух», «Сегодня: чтение / переписка / произношение».

### 3.4. Экран «Курс» (сейчас «Треки»)

- Заголовок «Курс» + строка: «Пять направлений. Занятие на сегодня само берёт из каждого — отсюда можно пройти любой модуль отдельно».
- Каждое направление: понятное название, одна строка «зачем», **уровень по направлению с подписью** («38 из 100» → тап: «Оценка по вводному тесту и твоим ответам в занятиях»), и **одна кнопка «Продолжить: модуль "Выпадение звуков"»**.
- Список модулей направления свёрнут; раскрывается по тапу. Статусы: ✓ пройден · ● **Ты здесь** · ○ впереди. У всех модулей не должно быть одинаковой кнопки «Тренировать» — выделен только текущий.
- Экран открывается прокрученным к самому слабому направлению или к последнему активному.

## 4. Экраны упражнений

### 4.1. Общее

Каждый экран упражнения содержит:
- **заголовок-инструкцию глаголом** и строку шагов;
- кнопку «?»;
- прогресс сверху понятно: «**Быстрая речь на слух** · 2 из 6» + тонкая полоса всего занятия по блокам;
- после ответа — понятный отклик, «послушать ещё раз», «перевод», «Дальше»;
- при первом появлении нового типа — однократная подсказка (коучмарк), куда нажимать;
- неактивные кнопки подписаны: «Сначала выбери ответ».
- Крестик выхода → «Прогресс сохранён — продолжишь с этого места. Выйти?».

### 4.2. Аудирование «Что прозвучало?»

- Инструкция: «Послушай фразу и выбери, что прозвучало». Звук играет автоматически.
- Шкала 0.75× / 1.0× / 1.25× подписана «Скорость» и объяснена по «?». Убрать дублирующую ссылку «Медленнее · 0.75×» — оставить один способ.
- **После ответа:** правильная фраза, подсвечено явление связной речи («next day → звучит как nex day: [t] выпал»), кнопка «Перевод», «Послушать ещё раз», «Послушать медленнее», «Дальше».
- «Не разобрал» — нормальный ответ, без штрафа; после него показывается разбор, как после ошибки.

### 4.3. Карточка готовой фразы (сейчас экран с «Записать себя»)

- Инструкция: «Послушай фразу и повтори вслух целиком». Шаги: «1. Слушай → 2. Повтори вслух → 3. Сравни (по желанию)».
- Английская фраза крупно, перевод под ней, «Ситуация: представиться» — мелко сверху.
- Две кнопки: **«Записать себя и сравнить»** и **«Сказал вслух → Дальше»**. Сейчас без записи двигаться дальше непонятно как.
- После записи: «образец → я → образец», распознанный текст (если доступно) с подсветкой расхождений, «Ещё раз» и «Дальше».

### 4.4. Карточки повторения

**Шаг 1 — вопрос.** Показано только нужное для вопроса. Инструкция по типу:

| Тип | Инструкция крупно | Что видно |
|---|---|---|
| Фраза/слово → значение | Прочитай вслух и вспомни, что это значит | английский текст + звук |
| На слух | Послушай и вспомни значение | только звук |
| **Скажи по-английски** | **Скажи по-английски: «{перевод}»** | **русский перевод крупно**, подсказка «первое слово» |
| Ложный друг | Как правильно сказать по-английски? | русское слово, варианты |

Кнопка внизу: **«Проверить себя»**.

**Шаг 2 — ответ** + вопрос «**Ты вспомнил?**».

**Шаг 3 — самооценка:**

| Было | Стало | Подпись |
|---|---|---|
| Снова | **Не вспомнил** | «покажу снова через 1 мин» |
| Трудно | **С трудом** | «повторим через 6 мин» |
| Хорошо | **Вспомнил** | «повторим через 10 мин» |
| Легко | **Легко** | «повторим через 8 дней» |

Интервалы словами: «через 10 мин», «завтра», «через 8 дней». При первой карточке — однократное объяснение: «Это интервальное повторение. Ты сам оцениваешь, насколько легко вспомнил. Чем легче — тем позже фраза вернётся. Честная оценка = меньше лишних повторов».

### 4.5. Чтение технических текстов

- Инструкция: «Читай. Незнакомое слово — нажми на него». Сохранить.
- У каждого абзаца — мелкая кнопка «Перевод абзаца» (перевод из данных контента; для «Моего текста» перевода нет — вместо неё «Объяснить с Claude»).
- Уже добавленные в карточки слова слегка подчёркнуты.
- Вверху понятно, что «1 из 6» — это абзацы или шаги: «Абзац 1 из 6».

### 4.6. Говорение с таймером («Быстрый ответ», перевод на лету)

- До старта — экран «Как это работает»: «Прозвучит вопрос. У тебя 5 секунд, чтобы начать отвечать. Говори 20–40 секунд. Идеально не нужно — нужно без долгих пауз». Кнопка «Понятно, начать».
- Таймер визуально понятен (круговой отсчёт + цифра), после ответа — чек-лист самопроверки с подсказками готовых фраз.

## 5. «Собеседование» (сейчас «Мой рассказ»)

- Вверху блок **«Как это работает»** (сворачиваемый): «1. Напиши ответ на вопрос — можно черновик по-русски и доработать с Claude → 2. Потренируй: послушай, повтори, расскажи по ключевым словам → 3. Пройди пробное собеседование».
- **Рекомендуемый порядок:** первым выделен «Tell me about yourself» с меткой «Начни с этого».
- Статусы ответов: «не написан» → «написан» → «отрепетирован ✓». Полоса «3 из 8 ответов готовы».
- Метка **STAR** — тап объясняет: «Схема рассказа: ситуация → задача → что ты сделал → результат».
- Пробное собеседование — наверху, но если готово меньше 3 ответов, подпись «Лучше сначала подготовь хотя бы 3 ответа» (не блокировать).

## 6. Счётчики, значки и термины (объяснение по тапу)

| Элемент | Объяснение |
|---|---|
| Очки (сигнал) | «Очки за занятия: время, точность, сказанное вслух. Чем больше — тем сильнее сигнал» |
| Дни в эфире | «Сколько дней подряд ты занимался хотя бы 10 минут. Один пропуск в неделю прощается» |
| Уровень ≈ B1 | «Примерная оценка по общеевропейской шкале A1–C2. B1 — можешь общаться на знакомые темы, B2 — свободно на работе» |
| Уровень по направлению (38) | «Твоя оценка по этому направлению от 0 до 100: вводный тест + ответы в занятиях» |
| Скорость 0.75× / 1.25× | «Скорость речи диктора. Цель — понимать на 1.0× и быстрее» |
| Ложные друзья | «Слова, похожие на русские, но с другим значением» |

В профиле — страница **«Как устроено приложение»** с этими объяснениями и кнопкой «Показать обучение заново».

## 7. Первый запуск и обучение интерфейсу

- После вводного теста — 3–4 экрана (пропускаемые): «Каждый день — одно занятие ~30 минут во вкладке "Сегодня"» → «Курс показывает пять направлений и где ты в каждом» → «Собеседование — готовим твои ответы» → «Тренировка — игры и тексты по желанию. Непонятно — жми "?" или на любой значок».
- Для существующего пользователя после обновления — один раз «Что изменилось» и предложение короткого обучения. **Прогресс не теряется.**

## 8. Контент

- Переводы: значения через «; », пояснение в скобках без запятой перед скобкой, без точки в конце. Правило в `check:content`, исправить существующие.
- У каждого предложения в текстах, диалогах и заданиях на аудирование должен быть русский перевод в данных (кроме «Моего текста»). Проверка в `check:content`.

## 9. Проверка понятности (обязательно)

1. **Прогулка новичка:** сбрось прогресс, пройди через Playwright на вьюпорте iPhone: первый запуск → вводный тест → «Сегодня» → занятие целиком (все блоки) → «Курс» → «Собеседование» → «Словарь» → «Тренировка» → профиль и настройки. Скриншоты каждого экрана и состояния.
2. Для каждого скриншота письменно ответь на три вопроса из п. 1.1. Где ответ неочевиден — исправь и переснимай.
3. Отчёт `docs/ux-audit.md`: экран → что было непонятно → что изменено → скриншоты «было / стало».
4. Проверь: перевод доступен одним тапом везде, где есть английский текст; ни одно упражнение не требует микрофона без альтернативы.
5. Обнови e2e под новые названия; добавь тест «у каждого экрана упражнения есть инструкция и кнопка "?"».

## 10. Порядок работы

1. Переименования (раздел 2) и навигация: вкладки, «Сегодня», экран занятия, «Курс» (раздел 3) — **деплой**, сообщи пользователю.
2. Экраны упражнений и карточки повторения (раздел 4) — **деплой**.
3. «Собеседование», счётчики, первый запуск, контент (разделы 5–8).
4. Проверка понятности (раздел 9) и итоговый отчёт пользователю: коротко, по-русски, со скриншотами ключевых экранов «было / стало».
