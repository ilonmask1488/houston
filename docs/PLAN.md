## Решения, принятые без вопросов (можно поменять)

- **Скорости 0.75 / 1.0 / 1.25** — один файл на скорости 1.0, остальное через `playbackRate` с сохранением высоты. Три файла на фразу утроили бы объём звука.
- **Голоса:** US — Ava/Andrew, UK — Sonia/Ryan, Индия — Neerja/Prabhat, Австралия — Natasha/William (edge-tts 7.2.8, доступен из сети пользователя на 26.09.2026).
- **Тест словаря** — формат «знаю / не знаю» с псевдословами (поправка на угадывание) и выборочной проверкой перевода; 6 полос: NGSL 1–500, 501–1000, 1001–2000, 2001–2809, NAWL, BSL. Адаптивная остановка после второй полосы, если знакомо меньше 25%.
- **Аудирование в тесте** — «лестница»: верно — следующая фраза быстрее, ошибка — медленнее; одна попытка переслушать.
- **Говорение** — запись + детектор речи по громкости (время до начала ответа, длительность, паузы > 2 с) + распознавание, если есть. Если телефон не даёт микрофон записи и распознаванию одновременно, дальше на нём работает только распознавание (оно в ТЗ главное).
- **CEFR** — среднее уровней словаря, слуха, чтения и речи с округлением вниз: лучше недооценить и дать лёгкий старт.
- **Повторный тест** — через 60 дней после предыдущего.
- **Тексты чтения** — собственные; NASA и Wikipedia — только с проверкой условий и атрибуцией (фаза 3).
- **Своё озвучивание** («Мой рассказ», «Мой текст») — синтез речи браузера: заранее сгенерировать чужой текст нельзя, а бэкенда нет.
